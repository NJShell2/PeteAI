What makes Pete different

Inspired by my personal Muse assistant (I named my Muse Barry the Bot), rebuilt from the ground up on Purdue infrastructure. The focus is on trust: your key stays yours, your data stays local, and you always hold the wheel.

🔑

Your key, remembered

First-run setup walks you through getting a GenAI Studio key. Paste it once, Pete AI encrypts it for your Windows user account, and you never enter it again. A connection test proves it works before you start.

💾

Local-first memory

Chats and workspace files live on your machine as the source of truth. The app keeps working during network outages, and nothing is uploaded anywhere unless you opt in.

Your API key

Pete AI talks to Purdue's GenAI Studio, and Studio needs to know who is asking. That is what your personal API key is for. You get it once, paste it once, and Pete AI remembers it from then on.

Go to Purdue GenAI Studio

Visit genai.rcac.purdue.edu and sign in with your Purdue account.

Create your API key

Generate an API key in Studio and copy it. Treat it like a password: it identifies you, and anyone holding it can use Studio as you. You may only be shown the key once, so copy it now.

Launch Pete AI

On first run, a setup modal appears automatically with these same instructions and a link back to Studio, so nobody has to guess where the key comes from.

Paste the key and test the connection

Paste your key into the setup modal and run the built-in connection test. It verifies the key against Studio live, so you know it works before you start chatting.

Done, it is remembered

Pete AI encrypts your key with Windows DPAPI, tied to your logged-in Windows account, and stores it in your per-user app data at %LOCALAPPDATA%\PurduePeteAI. A copy of that file is useless on another machine or another user account. You never reenter the key.

Key hygiene, non-negotiable

  • Keys are per person. On a shared machine, each user enters their own key once.
  • Never paste your key into chat, email, or a shared document.
  • If a key is ever exposed, revoke it and generate a new one at genai.rcac.purdue.edu. Deleting a copied key is hygiene, not remediation: only rotation invalidates a key someone else may already hold.
  • No key ever ships with Pete AI. Builds are assembled with an empty key store by design.

The roadmap

Where Pete AI goes next. Designed deliberately, built in order, no shortcuts.

👥

Pete Squad, for real

Parallel browser agents with per-agent screens, agent-to-agent messaging, and an orchestrator that delegates and synthesizes. The architecture is designed; the build is next.

☁️

Optional cloud sync

Opt-in sync of chat history through GenAI Studio, so a conversation can follow you between machines. Local-first stays the default; sync is a choice, not a requirement.

📧

Outlook, calendar, Teams

Long-term aspiration: reach Microsoft 365 through the Graph API, not the browser. Read-only first, human confirmation before any write, and only within whatever Purdue IT permits. Authentication is the real work here, and it gets decided before a line of integration code.
